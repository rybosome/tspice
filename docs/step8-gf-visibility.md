# Occultation and field-of-view windows

The three raw Geometry Finder methods take a positive sampling step in TDB seconds, a confinement window and a distinct, preallocated result window. The result replaces the prior intervals. Read its cardinality with `wncard` and its closed endpoints with `wnfetd`. An empty result is a successful search. Each input interval must be sampled finely enough to detect the events of interest. `gfstol` determines the boundary convergence tolerance. The search sets the process/module-wide GF step observable through `gfstep`. Existing initialized steps are restored after parity workflows. CSPICE provides no operation to return a runtime to the initial unset state. [Typed API](../packages/backend-contract/src/domains/geometry-gf.ts)

| Method   | Scientific interpretation                                                                                                                                                                                                                                |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gfoclt` | Select full, partial, annular or any occultation of the back body by the front body. Shape, body-fixed frame and observer apply to the named bodies. The supported ellipsoid, point and unprioritized DSK combinations retain their toolkit diagnostics. |
| `gfrfov` | Find when an inertial or rotating-frame ray lies in the instrument field of view. The ray need not be normalized. NAIF accepts NONE, S and XS corrections for rays.                                                                                      |
| `gftfov` | Find when the instrument sees the target center (POINT) or any part of its apparent limb (ELLIPSOID). A point target accepts an empty target frame.                                                                                                      |

The Node addon serializes the calls under the CSPICE lock. The WASM adapter snapshots the ray once and releases its input strings, ray buffer and diagnostics on all paths. Both pass real double windows to the matching compiled N0067 entry point. Passing the same window twice lets N0067 clear confinement before reading it. Both wrappers reject that alias, expired handles, nonfinite inputs and a positive step too small to advance an epoch within a confinement interval. Independent real error cases exercise invalid steps, shape combinations, frames, instruments, corrections and insufficient result capacity.

The 56 registered workflows compare all result and confinement interval endpoints with locked SpiceyPy 6.0.3, including 30 genuine terminal diagnostics. A synthetic instrument points along a moving CK axis. Its ray enters at ET 2.4056487083 and leaves at ET 7.5943512917. In a separate circular camera, the moving target's center crosses at ±50 seconds, as predicted by the ratio of its transverse and axial distances. Its apparent limb extends visibility to about ±71.36 seconds. The partial-occultation intervals flank a full occultation at the midpoint. Instantaneous `fovray`, `fovtrg` and `occult` corroborate those boundaries. The independent midpoint check uses NAIF's +3 code for a full occultation of the second body by the first.

# Frame metadata and transformations

D03 adds six methods to `FramesApi`. The existing parity fixtures supply the rotating Euler frame and signed TK class ID in `audit-frames.tf`, a matrix and angles frame in `audit-geometry.tf`, and NAIF body axes and orientation coefficients in `pck00010.tpc`. No spacecraft observation is implied by the synthetic frames. [Fixture provenance](../packages/py-parity-checking/fixtures/README.md) [NAIF frames](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/frames.html)

| Method                           | Observable result and conditions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bltfrm(frameClass, ids)`        | Replaces a live caller-owned integer cell with sorted built-in frame IDs. In N0067, −1 selects all 145 frames. Classes 1 through 6 require the same minimum capacity, including classes with no members. Invalid class precedes the size error.                                                                                                                                                                                                                                                                        |
| `pxfrm2(from, to, etfrom, etto)` | Nine row-major elements transform coordinates of a fixed vector between frame orientations at two independent TDB epochs. Each leg needs its own coverage. Swapping frame names and epochs transposes the rotation.                                                                                                                                                                                                                                                                                                    |
| `tipbod(ref, body, et)`          | Inertial-to-PCK-body rotation at ET. The argument is a PCK class ID. Binary PCK data can take precedence over text data. Coverage here uses text PCK.                                                                                                                                                                                                                                                                                                                                                                  |
| `tisbod(ref, body, et)`          | All 36 row-major entries include the lower-left rotation derivative per second. The public test independently checks both diagonal blocks and all nine derivative components against a centered rotation difference at ±0.125 s.                                                                                                                                                                                                                                                                                       |
| `tkfram(typeId)`                 | TK-to-base rotation and numeric base frame ID exposed only when the returned flag is true. On the pinned source each ordinary success sets true. Unknown IDs signal INCOMPLETEFRAME and zero signals ZEROFRAMEID. An FK class ID can differ from its frame ID.                                                                                                                                                                                                                                                         |
| `xfmsta(state, from, to, body)`  | Six coordinates and rates, in km, radians and seconds. Rectangular, cylindrical, latitudinal and spherical forms have different order. Geodetic and planetographic states use longitude, latitude and altitude. Unequal spheroid conversions require equal equatorial axes. Planetographic positive longitude depends on body rotation or pool override. An equal-system conversion copies the state before body lookup. The public C wrapper still checks every string, including a body used as a blank placeholder. |

The original C cell descriptor is synchronized only after successful BLTFRM. Its translated callee clears the control cardinality before checking class and size. Reset cardinality explicitly after such an error. Both adapters check live integer cell ownership. Node also checks the process-wide native registry while holding the CSPICE lock. WASM resolves instance-local opaque tokens and frees each acquired buffer on all exits. A genuine empty class is compared by full cardinality and elements. Toolkit errors are captured and reset before another request.

## Pinned numerical and error behavior

N0067 `pxfrm2.c` calls REFCHG twice and then MXM unconditionally on automatic matrices. A failing REFCHG may leave a matrix unwritten. The shared adapter resolves both names and checks the two exact REFCHG calls into initialized scratch under serialized state. On a leg failure it returns the recorded CSPICE diagnostic, preserving the PXFRM2 trace. For success and ordinary unknown/empty names it dispatches to `pxfrm2_c`. The locked oracle independently uses the library symbol `refchg_` with explicit signed-integer and double-pointer ABI for the leg check. Successful results come from `sp.pxfrm2`. The missing-orientation cases never invoke the defective arithmetic path. [Shared C adapter](../packages/backend-shim-c/src/domains/frames.c) [Independent oracle](../packages/py-parity-checking/sidecars/spiceypy/src/py_parity_sidecar/frame_transform_oracle.py)

Pinned matrix wrappers transpose output even on some errors. The adapters provide initialized matrix storage and copy out only after successful status, and after checking the TK flag. Four matrix-returning methods preserve each numeric output, including IEEE exceptional components. For finite synthetic PM coefficients and ET yielding an overflowing orientation polynomial, all nine TIPBOD and 36 TISBOD classifications are compared to the locked library; such a matrix has no physical rotation interpretation. XFMSTA accepts only finite six-component input; the three rates are transformed by the actual toolkit Jacobian. On-axis axial rates are preserved according to the native conventions, while transverse polar rates raise INVALIDSTATE. [Public cross-backend tests](../packages/py-parity-checking/test/frame-metadata.test.ts)

Frame definitions and PCK models must be valid and physically applicable at the requested epoch. N0067's integer hashes use signed absolute value. Direct TIPBOD, TISBOD and TKFRAM reject the minimum signed 32-bit ID; unequal spheroid XFMSTA conversions check paired pool body mappings before lookup. PXFRM2 checks resolved endpoint IDs. The direct body orientation paths also validate safe integer conversion of a supplied text PCK maximum phase degree when phase coefficients exist. The initial header declarations, actual routines, guards and registration can be inspected together. ## Validation

The 54 workflows have 145 steps and 105 new-method calls. Twenty-nine workflows expect genuine toolkit errors. Both compiled backends passed all 108 registered comparisons. Eight public checks cover ownership, recovery, matrix direction, finite differences and exceptional components. The native boundary suite passed eight tests; the real-module WASM suite passed 37, including short/long/trace allocation failures. A real Chrome worker exercised all six methods, freed its caller cell and recovered from BADFRAMECLASS. Required full local and canonical CI evidence is recorded separately.

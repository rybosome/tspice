# Osculating elements and two-body propagation

E01 adds five kernel-independent operations to the raw ephemeris domain. Input states give inertial position in km and velocity in km/s. Epochs are seconds past J2000 TDB and central gravitational parameters are in km³/s². All inputs are finite. Both backends copy caller-owned fixed-length tuples before entering CSPICE and return newly owned arrays. [CONICS](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/conics_c.html) [OSCELT](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/oscelt_c.html)

| Operation                                                                        | Input and observable output                                                                                                                             |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [conics](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/conics_c.html) | Eight classical elements and an ET produce a six-component state for an elliptic, parabolic or hyperbolic conic.                                        |
| [eqncpv](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/eqncpv_c.html) | Evaluation ET, element epoch, nine equinoctial elements and the reference pole's right ascension and declination in radians produce the inertial state. |
| [oscelt](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/oscelt_c.html) | The state, its epoch and central GM produce eight classical elements.                                                                                   |
| [oscltx](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/oscltx_c.html) | Returns the classical elements, then true anomaly in radians, semimajor axis in km and period in seconds.                                               |
| [prop2b](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/prop2b_c.html) | Central GM, initial state and signed elapsed seconds produce the propagated state in the same inertial frame.                                           |

## Element order and conditioning

Classical elements are periapse distance, eccentricity, inclination, ascending-node longitude, periapse argument, mean anomaly at epoch, epoch and central GM. Angular elements and mean anomaly use radians. Hyperbolic solutions use their own mean anomaly convention. CSPICE supplies conventional angular elements for circular and equatorial orbits. Nearby orbits can give poorly conditioned angular elements. Regime changes near eccentricity one also demand care. The exact parabolic fixture uses an axis-aligned state at escape speed. [OSCELT](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/oscelt_c.html)

The nine equinoctial elements are semimajor axis, H, K, mean longitude, P, Q, periapse-longitude rate, mean-longitude rate and node-longitude rate. Rates use radians per second. Changing the reference pole changes the frame orientation. N0067 accepts eccentricity exactly 0.9 and signals ECCOUTOFRANGE above it. Its velocity calculation divides the periapse-longitude rate by the mean-longitude rate. At zero mean-longitude rate, the independent oracle observations retained three finite position components and three NaN velocities in each of two cases. A nonzero-rate control compares all six finite components. ## OSCLTX result and error handling

The N0067 header defines `SPICE_OSCLTX_NELTS` as 20 for the native output allocation. Its implementation clears slots 8 through 19 before deriving any elements. The shared shim supplies the full allocation, checks the CSPICE error state, then copies the eleven defined fields. Nonelliptic periods are zero. An uncomputable semimajor axis or period can also be zero. [OSCLTX](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/oscltx_c.html) [Shared native and WASM shim](../packages/backend-shim-c/src/domains/ephemeris.c)

SpiceyPy 6.0.3 returns eleven fields from its 20-word OSCLTX allocation. That wrapper omits the error-check decorator, so a failing call can appear to return data while SPICE still holds NONPOSITIVEMASS or DEGENERATECASE. Immediately after the wrapper call, the independent handler invokes SpiceyPy's own error check before inspecting the array. The five registered OSCLTX error workflows cover nonpositive central GM, rectilinear motion, zero position and zero velocity. [Independent handler](../packages/py-parity-checking/sidecars/spiceypy/src/py_parity_sidecar/handlers/ephemeris.py) [Registered OSCLTX workflows](../packages/py-parity-checking/src/cases/ephemeris/oscltx.cases.json)

## Execution scope

The 51 registered workflows contain 105 calls, with 22 expected scientific-error workflows. Each successful comparison retains all state or element fields. Inputs are authored numeric examples spanning unit-scale and km-scale systems, inclined and retrograde geometry, bound and unbound orbits, positive and negative elapsed times, and invalid physical parameters. No kernels or external data are required. Supplemental public checks measure circular-orbit energy and angular momentum, round-trip elliptic propagation and compare the shared classical fields and extended-element conventions.

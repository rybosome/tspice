# User-defined Geometry Finder functions

| Raw method                                                                                | Observable behavior                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `udf(et, initialValue = 0)`                                                               | Runs the toolkit's dummy scalar callback. N0067 adds positive zero to the supplied output word. Nonzero finite values survive, including subnormals. An initial negative zero returns positive zero.                       |
| `uddf(scalar, x, dx)`                                                                     | Samples the callback at `x - dx` and then `x + dx`. QDERIV combines the scaled endpoint values. A negative step reverses the callback order. Nonfinite derivative results from finite samples retain their IEEE values.    |
| `uddc(scalar, x, dx)`                                                                     | Tests whether that centered derivative is strictly negative. A zero derivative and a NaN derivative both return false.                                                                                                     |
| `gfudb(scalar, predicate, step, confinement, result)`                                     | Calls the predicate with the original scalar function and epoch. Returns all true intervals through the caller's result window. A predicate may ignore the scalar or call it at its chosen epochs.                         |
| `gfuds(scalar, isDecreasing, relate, refval, adjust, step, nintvls, confinement, result)` | Uses the user-supplied decreasing test to partition the scalar function and find inequality, equality or extremum events. The result window capacity and the internal workspace interval count control separate resources. |

Epochs and steps use TDB seconds. Supply finite scalar callback results and boolean predicate results. Confinement and result are distinct owned windows. Each search snapshots confinement into private storage and publishes the complete result only while the original output claim remains live. A callback may release that claim and allocate another window at the same address. A generation check prevents the pending search from overwriting the replacement. The 256 MiB workspace guard covers all 15 internal GFUDS work cells before N0067 doubles its signed interval count. Nonpositive counts reach the toolkit's VALUEOUTOFRANGE diagnostic. ## Callback execution

A direct synchronous client calls a synchronous scalar or predicate on the same call stack. The native addon serializes CSPICE entry and permits supported reentrant calls by the current thread. For example, a decreasing predicate can call `uddc` on the scalar argument that GFUDS supplied. Normal function values stay in their host process. The worker transport registers callbacks for the lifetime of the original request and exchanges invocation and reply messages. A worker may suspend its WASM invocation while a page callback awaits a supported read on the same client. Request and slot identifiers associate the reply with its initiating operation. Cancellation, disposal and stale replies are handled by the transport. [Worker callback protocol](../packages/tspice/src/worker/transport/gfCallbacks.ts) · [WASM callback lifetime](../packages/backend-wasm/src/codec/gf-callbacks.ts)

N0067 stores the currently selected scalar and predicate in global callback slots. Starting a second user search during the first one would replace those slots. The wrapper rejects that nested search before entering the toolkit. The direct synchronous derivative path supports nested derivative evaluations. WASM permits one suspended asynchronous GF invocation per module. Workers can issue independent read operations that complete before the original callback returns. The four function-bearing raw calls bypass optional result caching so each call reaches the supplied functions. ## Scientific comparisons and repairs

The 47 registered workflows execute 170 steps, including 100 calls to the five target routines. Both Node and WASM matched all 47 workflows. Derivative cases compare the returned quantity and both ordered callback epochs and values. Search cases compare every scalar sample, every predicate sample and boolean, all result endpoints and the original confinement endpoints. The equations are kernel-free. Constant, affine, quadratic and cubic functions distinguish monotonicity changes, disjoint intervals, equality singletons and adjusted absolute extrema. A pre-populated result, empty confinement and true/false predicates that never call their scalar exercise the callback and window boundaries. [Registered cases](../packages/py-parity-checking/src/cases/geometry-gf) · [Independent callbacks](../packages/py-parity-checking/sidecars/spiceypy/src/py_parity_sidecar/gf_user_oracle.py)

Eleven workflows end with expected toolkit errors. With room for one interval, the same two-component result produces WINDOWEXCESS in GFUDB and CELLTOOSMALL in GFUDS. Other registered errors are INVALIDSTEP, EMPTYSTRING, NOTRECOGNIZED and VALUEOUTOFRANGE. The reference uses the locked SpiceyPy 6.0.3 public callback/search wrappers and an independent `udf_c` binding when the accumulator is explicit. An isolated locked Python 3.11.17 environment with NumPy 2.4.4 passed the 94 registered runtime comparisons and six supplemental tests. The focused macOS arm64 reference library SHA-256 was `3dc7060bc5c2f21ed799f86a490e765f9abac4107330d9cfc4c533193e121523`.

The pinned UDDF wrapper previously continued after failed callbacks and read a private QDERIV result after division by zero. Both builds stage a checked copy of the pinned source and return through the original error trace immediately after a failed producer. The live oracle calls stock UDDF/UDDC with defined nonzero-step inputs. A separate test obtains DIVIDEBYZERO directly from the locked QDERIV and verifies the protected backend's error, sample order and successful reuse. Additional probes compare positive infinity, negative infinity and NaN in derivative results, factorization of the centered cubic difference and analytic event endpoints. The real Chrome worker matched all five methods, including the complete two search windows, original callback exception and subsequent derivative. A suspended callback made a successful read on the same worker. Another callback freed its output claim and allocated a replacement. The search reported its expired output and the replacement retained its own interval. [WASM allocation checks](../packages/backend-wasm/test/gf-user-allocations.test.ts)

`spiceClients.toWebWorker()` returns a `SpiceWorker`. Its numeric and predicate callbacks may return promises, and each predicate receives the original scalar with its precise synchronous or asynchronous result type. A callback can await an ordinary measurement on the same worker. One callback operation may suspend a WASM instance at a time. In-process native callbacks return synchronously.

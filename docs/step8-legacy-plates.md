# Legacy type 2 plate geometry

These seven N0067 routines take an open DAS reader and its traversed DLA segment descriptor. The public methods live in `DskApi`, together with DSK item reads and intersections. All seven retain their canonical names. Coordinates use km, angles use radians and epoch values use TDB seconds past J2000. The caller owns each returned point, row and plate-ID array.

| Raw method        | Observable geometry                                                                                                                                                                                                                                                          |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `illum_pl02`      | The direction of the supplied point selects the facet by a radial ray. The facet normal and the supplied point determine phase, solar incidence and emission angles.                                                                                                         |
| `illum_plid_pl02` | Given a surface point on the specified one-based facet of a latitudinal segment, return target epoch, observer-to-point vector, three angles and independent visible/lit booleans. N0067 reports FRAMENAMENOTFOUND for a rectangular segment at its coordinate-system check. |
| `limb_pl02`       | Sample the reference ellipsoid's limb about the observer, project onto the selected mesh and return target epoch, observer position, ordered plate-model points and corresponding IDs.                                                                                       |
| `llgrid_pl02`     | Trace inward radial rays through ordered longitude/latitude pairs. Empty and repeated grids retain their shape. A ray missing the selected component raises NOINTERCEPT.                                                                                                     |
| `subpt_pl02`      | INTERCEPT and ELLIPSOID NEAR POINT choose different rays. Return the sub-observer point, signed observer altitude and facet ID.                                                                                                                                              |
| `subsol_pl02`     | The chosen method locates a subsolar point. Its reported distance is measured from the observer to the point. Both distances use km.                                                                                                                                         |
| `term_pl02`       | Project the extended-source UMBRAL or PENUMBRAL ellipsoid terminator samples onto the mesh. Return target epoch, observer position, ordered term points and their facet IDs.                                                                                                 |

The adapters snapshot finite input coordinates and the eight descriptor words once, validate the active owning handle and physically check the descriptor in the open file. They check signed integer parameters and sufficient output sizes before calling the native ABI. The shared 256 MiB per-buffer policy permits up to 11,184,809 rows with four leading epoch/observer words. Empty grids and nonpositive cut counts have nonnull scratch storage. A zero-point grid succeeds. With valid geometry prerequisites, LIMB_PL02 raises INVALIDCOUNT and TERM_PL02 raises INVALIDSIZE for nonpositive counts. Results are read after the toolkit status check. Optional transported cache paths reread the file and active kernel state.

## Independent scientific calls

SpiceyPy 6.0.3's public Python module lacks all seven entries. Its independently built N0067 shared library exports all seven exact symbols. The reference declares the C ABI on a separate library handle, verifies the scalar and descriptor widths, allocates complete output buffers and reads the results after checking the primary toolkit error. Both execution paths select the physical DLA descriptor through their own DAS reader. The macOS arm64 reference library used for the focused runs had SHA-256 `3dc7060bc5c2f21ed799f86a490e765f9abac4107330d9cfc4c533193e121523`. The registered workflow uses the locked wheel on each CI host. [Independent typed binding](../packages/py-parity-checking/sidecars/spiceypy/src/py_parity_sidecar/legacy_plates_oracle.py)

The fixtures use project-authored ephemerides and an octahedron with semiaxes 3, 2 and 1 km. The dedicated generator repacks its oriented triangles into a latitudinal type 2 segment and derives its radial bounds with DSKRB2. The comparison also uses the original rectangular model and the isolated off-center segment of the disconnected mesh. The frame supplement assigns the body-fixed frames and specifies a spherical 1 km light source. [Fixture generator](../packages/py-parity-checking/fixtures/generate-legacy-plates.py) · [Frame and source constants](../packages/py-parity-checking/fixtures/kernels/audit-legacy-plates.tf)

Independent comparisons span 57 workflows, 388 steps and 92 direct target calls. Twenty-nine workflows terminate with expected toolkit errors. Supplemental checks calculate facet angles from the plane normal and the observer and Sun positions, both explicit point distances and the triaxial facet equation for every limb and terminator row. Real Chrome called every worker method and compared all result fields, including cut order, IDs and flags, then exercised a bad plate ID and successful empty-grid reuse. ## Pinned build behavior

Both builds use the N0067 scientific entries and preserve the E20 checked 2 MiB WASM traversal stack. Checked source edits stop computation when a producer has signaled an error. They preserve the primary diagnostic before private output from DSKX02, SPKAPO's stellar transform, the SPKACS stencil, SPKAPS/ZZSPKFAP, SPKCVO/T or the distorted limb-plane chain can be consumed. The legacy limb and terminator routines now signal MEMORYFAILURE on failure to allocate their own angular grid. The subsolar ellipsoid-near-point path checks the returned RADII count before reading three values. A wrong pool type keeps the actual BODVRD diagnostic. A short numeric array signals INVALIDCOUNT on the protected backend. Tests of that short array run on the corrected backend. [Build-tree guards](../scripts/stage-legacy-plates.mjs) · [WASM allocation tests](../packages/backend-wasm/test/legacy-plate-allocations.test.ts)

E21 stacks on E20 and directly reuses its descriptor checks, checked traversal stack, two capacity fixes in LIMBPT and original fixtures. The same five-byte aberration cache implementation used in the E08 stack is staged here because the legacy methods descend into those routines. Cache hits require all significant bytes to fit the saved key. When integrating the E08 and E20 stacks, retain one shared cache implementation plus both LIMBPT capacity checks and regenerate the native and WASM artifacts.

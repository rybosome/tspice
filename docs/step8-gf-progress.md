# GF interrupts and progress updates

The Geometry Finder flag starts clear. Calling `gfinth(2)` invokes the N0067 interrupt handler, which installs itself for SIGINT and sets the runtime’s shared flag. `gfbail()` returns this boolean without consuming it. `gfclrh()` clears it. Kernel and error resets preserve the flag. Other signed signal numbers reach N0067’s INVALIDSIGNAL diagnostic. Calling the explicit handler in a browser worker installs its disposition inside that worker’s Emscripten module. Browser keyboard or host OS events have no automatic route to the worker. [Raw contract](../packages/backend-contract/src/domains/geometry-gf.ts)

On native Node, SIGINT is a process-wide resource. On first ownership the addon saves the prior host disposition. Multiple clients can hold a claim, and repeated calls by one client do not acquire additional claims. The last owner’s disposal restores the previous host handler if the GF handler still owns SIGINT. A worker environment cleanup hook releases abandoned claims. The shared N0067 flag is staged as a lock-free atomic integer so an asynchronous native signal and a simultaneous poll access it safely. Each platform compiles its own verified N0067 source into ignored build output. [Flag staging](../scripts/stage-gf-signal-flag.mjs)

An in-process client created by `spiceClients` releases its own native backend resources before clearing kernels. Caller-supplied backend instances retain their existing ownership. A fresh child process with alternating sync and async owners installs a real Node SIGINT listener, receives SIGINT via GF, disposes the first owner, receives another interrupt through the second, and then receives the final SIGINT on the restored Node listener. The first disposal test identified a missing call to the existing backend cleanup hook in the public client. Two separate WASM module instances also verify independent flag state. [Lifecycle tests](../packages/py-parity-checking/test/gf-interrupt.test.ts)

Use `gfrepi` to start a progress report, `gfrepu(ivbeg, ivend, time)` to update it and `gfrepf` to finish. The three finite inputs are TDB seconds. N0067 accepts both endpoints and backward progress within the interval. Reversed endpoints and epochs outside the interval raise documented diagnostics. Output uses a one-second wall-clock gate and a four-call update cadence. An initialized two-interval report of total duration 40 seconds receives updates reaching five seconds of progress. Its actual output contains 12.50%, with the same prefix, suffix, erase characters and finalization as the independently linked SpiceyPy reporter. [Live stdout comparison](../packages/py-parity-checking/test/gf-reporter-output.test.ts)

The four methods dispatch to their matching public C routines under the native lock or through the compiled WASM export. Caching bypasses state observations and reporter calls. Twenty-seven registered workflows compare flag transitions, repeated operations, reset behavior, progress inputs and genuine failures on both compiled runtimes. Supplementary tests cover observable reporter output, actual host signal delivery, wrapper validation and every WASM input/output allocation. A real Chrome worker observed the complete flag sequence and reporter recovery after a rejected progress epoch. All inputs use synthetic time intervals and process-local signal state. [Registered cases](../packages/py-parity-checking/src/cases/geometry-gf)

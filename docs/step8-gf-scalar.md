# Scalar Geometry Finder searches

These six raw methods replace the contents of a preallocated result window with the TDB times that satisfy a physical condition. They preserve the distinct confinement window. Read every closed interval with `wncard` and `wnfetd`. A local extremum or equality can return a singleton. Multiple disjoint intervals and an empty result are valid. The sampling step must resolve the events of interest, and `gfstol` controls time refinement. Each search sets the process or module's active GF step. [Raw contract](../packages/backend-contract/src/domains/geometry-gf.ts)

| Method   | Scalar measurement                                                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gfpa`   | Phase angle at the target, between the illuminator and observer, in radians.                                                                                                                                                    |
| `gfposc` | A coordinate of the target position relative to the observer, in the requested frame and coordinate system.                                                                                                                     |
| `gfrr`   | Signed range rate in km/s. A positive value indicates increasing range.                                                                                                                                                         |
| `gfsntc` | A coordinate of a ray's surface intercept, expressed in the specified target-fixed frame. The ray can point away from the target during part of confinement. CSPICE restricts the search to the applicable intercept intervals. |
| `gfsubc` | A coordinate of the sub-observer point, using the supplied shape method and target-fixed frame.                                                                                                                                 |
| `gfilum` | Phase, incidence or emission angle in radians at a specified surface point in target-fixed km.                                                                                                                                  |

Cartesian distances use km, angular coordinates use radians, and rate adjustments use km/s. For an absolute-extremum relation, a positive adjustment selects a range about the extremal value in the units of the scalar. The workspace interval count is separate from output capacity. The shared shim bounds the aggregate temporary windows to 256 MiB, using each routine's N0067 workspace multiplier. It rejects expired or aliased windows, nonfinite quantities and steps that cannot advance the confinement epoch. The serialized Node addon and compiled WASM export call the matching native search. Both snapshot three-vectors once and bypass the optional result cache for these mutating operations.

The authored trajectory gives a target position of (20, −0.1t, 0) km relative to the moving observer. Its signed range rate is 0.01t / sqrt(400 + 0.01t²) km/s. A ray along +X intersects the visible surface at y = 0.1t. The sub-observer point lies on the center-to-observer line and the triaxial ellipsoid. At its near equatorial vertex, the emission angle satisfies tan(angle) = |0.1t| / 17. Eight public checks compare these independent observations, check phase against an instantaneous measurement, and exercise mutable windows, cache and disposal.

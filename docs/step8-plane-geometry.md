# Plane and line geometry

E10 adds eight raw operations in the existing geometry domain. Node and WASM both call the matching N0067 C entry point. The public plane is a four-number tuple containing the three normal components and the distance constant. Vectors and plane inputs are finite, fixed-length snapshots. Callers supply canonical planes with unit normals and nonnegative distances. A computed plane with an infinite constant can be inspected as a result. [NAIF planes required reading](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/planes.html)

## Inverse projection at its representability limit

Pinned VPRJPI uses the dot product of the two plane normals as its denominator. Its numerator is the inverse plane constant minus the dot product of the input point and the inverse plane normal. The absolute denominator must strictly exceed `(10 / DPMAX) * max(1, abs(numerator))`. Equality returns absence, including when the numerator is zero. The public result omits the undefined output vector on absence. [VPRJPI](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/vprjpi_c.html)

The public comparison uses a projection plane at x = 0, input point (0, 2, −3), and represented unit inverse normals (d, 1, 0). For numerators 0, 0.5 and 2 it checks the floating-point numbers immediately below and above the positive threshold, the threshold itself, and the negative of the adjacent higher magnitude. All twelve found flags and all hit coordinates agree with the locked native oracle. The oblique round trip separately reconstructs a plane and a projected point using independent spans. Axis-aligned zero or collinear vectors exercise documented singularities without depending on cancellation of nearly equal products. ## Finite input and IEEE results

A point with two components equal to the largest finite double can produce an infinite plane constant for a diagonal unit normal. Projection can likewise produce two NaNs and a signed infinite component, while a nearest point on a line can remain finite even though its distance overflows. A nonzero subnormal line direction can yield NaNs when the internal projection rescales it. Focused tests tag IEEE results for JSON transport, retain every component, and compare finite controls with the actual locked wrappers. They never use an infinite plane constant as an input plane.
